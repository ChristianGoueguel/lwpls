`lwpls` is parsnip wrappers to fit locally-weighted partial least
squares models, for regression or classification tasks.

## Installation

Install the development version from [GitHub](https://github.com/) with:

``` r
# install.packages("devtools")
devtools::install_github("ChristianGoueguel/lwpls")
```

## Example

Here is a simple model using a simulated data set contained in the
package:

``` r
library(rnirs)
library(lwpls)
```
